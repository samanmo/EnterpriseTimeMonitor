
====================================================================
           HR TIME TRACKER - LOCAL BUILD & RUN INSTRUCTIONS
====================================================================

1. PROJECT DIRECTORY SETUP
--------------------------
Ensure all your files are inside a single folder with this structure:
  YourProjectFolder/
    ├── CMakeLists.txt
    ├── TimeTracker.pro
    ├── TimeTracker.h
    ├── TimeTracker.cpp
    ├── main.cpp
    └── schema.sql

2. POSTGRESQL DATABASE INITIALIZATION
--------------------------------------
Open your PostgreSQL terminal (psql or pgAdmin) and execute:

  -- Create the database
  CREATE DATABASE hr_database;

  -- Create the user used in your source code
  CREATE USER hr_admin WITH PASSWORD '12345678';

  -- Grant permissions
  GRANT ALL PRIVILEGES ON DATABASE hr_database TO hr_admin;

Now run the queries inside 'schema.sql' to build the tables and inject test data.

3. OPTION A: COMPILING WITH QT CREATOR (RECOMMENDED)
-----------------------------------------------------
  1. Open Qt Creator.
  2. Choose "File" -> "Open File or Project...".
  3. Select either "CMakeLists.txt" or "TimeTracker.pro".
  4. Select a desktop compiler kit matching Qt 6.x.
  5. Click the green "Run" button in the bottom left corner.

4. OPTION B: COMPILING VIA COMMAND LINE (CMAKE)
-----------------------------------------------
Open your shell terminal inside 'YourProjectFolder/' and execute:

  mkdir build
  cd build
  cmake ..
  cmake --build .
  ./HRTimeTracker
